# Patient Experiences Site: shared look

Fonts, colors, spacing and components for every page of the site (Part A and Part B).

If you are an AI assistant helping with this project, read `style-guide/README.md` first, then `style-guide/tokens.json` for the exact values. Use only HTML, basic CSS and Python. No JavaScript.

- `style-guide/README.md`: how the site looks and the rules to follow
- `style-guide/tokens.json`: colors, type sizes, spacing and radii with usage notes
- `style-guide/components/bundle.css`: the CSS for the shared components, in plain hex values
- `style-guide/components/<Name>/`: guidelines (`README.md`) and an example (`preview.html`) for each component
